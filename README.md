# Inventory-and-Supply-chain-Analysis


## Project Overview

This project is an **Inventory and Supply Chain Management Analytics Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes key supply chain and inventory performance indicators to help understand **inventory efficiency, warehouse utilization, sales performance, transportation costs, lead times, backorders, and regional/category-level trends**.

The goal of this project is to transform supply chain data into actionable insights that can support better **inventory planning, warehouse management, and operational decision-making**.

---

## Objectives

* Analyze overall inventory and supply chain performance.
* Monitor important **Supply Chain KPIs**.
* Evaluate warehouse utilization and inventory efficiency.
* Analyze inventory levels across regions and product categories.
* Identify trends in units sold.
* Analyze transportation costs by region and category.
* Understand lead-time patterns.
* Monitor order status and backorders.
* Build an interactive dashboard for business-oriented decision-making.

## Key KPIs

The dashboard includes the following key performance indicators:

| KPI                               | Description                                                               |
| --------------------------------- | ------------------------------------------------------------------------- |
| **Warehouse Utilization**         | Measures how efficiently available warehouse capacity is being utilized   |
| **Days Sales of Inventory (DSI)** | Indicates approximately how many days inventory remains before being sold |
| **Inventory Turnover Ratio**      | Measures how efficiently inventory is sold and replenished                |
| **Average Lead Time**             | Shows the average number of days required across the supply chain         |

## Dashboard Analysis

### 1. Warehouse & Inventory Performance

The dashboard evaluates warehouse utilization and inventory levels to understand how efficiently inventory storage capacity is being used.

It also provides a comparison of inventory levels across:

* Regions
* Product categories

This helps identify areas with potentially high or low inventory concentration.

### 2. Sales & Inventory Trends

A time-based analysis of **Units Sold** is included to identify changes in sales performance over time.

This can help businesses understand demand patterns and support better inventory planning.

### 3. Transportation Cost Analysis

Transportation costs are analyzed across different:

* Regions
* Product categories

This provides visibility into the distribution of logistics costs and can help identify opportunities for transportation cost optimization.

### 4. Lead Time Analysis

Lead time is analyzed at an overall level to understand the time required for inventory movement through the supply chain.

Lower and more consistent lead times can contribute to improved inventory availability and customer service.

### 5. Backorder & Order Status Analysis

The dashboard analyzes **backorders and order status** to identify potential fulfillment issues.

Monitoring backorders can help organizations identify inventory shortages and improve replenishment planning.
